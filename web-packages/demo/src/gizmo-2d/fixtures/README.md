## 操作验收

1. 在 Demo 创建菜单选择“FFD 与晶格测试案例”。确认红色基础网格和青色已变形晶格均可见；使用下方晶格步骤验证选择和变形。
2. 选择“运动路径编辑测试案例”。确认蓝色曲线/方形路径点、灰蓝控制线、琥珀色圆形控制柄可区分，悬停与选中有高亮。拖动路径点时相邻控制柄联动，Shift 限定主轴，Alt 单独调整控制柄；编辑末端点发出的关键帧时间为 2.74 秒，播放头不随编辑跳转。拖动元素本体、X/Y 箭头或修改属性面板坐标，整条路径应一起移动；Escape 取消移动时元素与路径一起恢复，重新采样不会跳回旧位置。
3. 选择“渐变色编辑测试案例”。初始为弧向渐变；分别切换纯色、径向、线性、弧向。渐变间保留端点和色标，纯色时不显示渐变手柄。
4. 在线性渐变的线段旁新增色标；在面板选择该色标并修改颜色、不透明度，画布立即刷新，其他色标不受影响。切到纯色再切回渐变，保留本页此前的渐变配置。
5. 点击“结束编辑”。横轴移动显示左右箭头，Alt 拖动上下改变 X 旋转并显示上下箭头；纵轴移动显示上下箭头，Alt 拖动左右改变 Y 旋转并显示左右箭头。
6. 悬停/点击锚点，看到小手光标和两行归一化坐标。拖动时为抓取手形，图形保持原位；背景随文本宽度变化，两行文字在半透明黑色区域中居中。

### 晶格增强验收

1. 点击 A，Shift 点击 B，面板显示 2 个控制点；Shift 再点击 A 后只保留 B。Shift 按住选点拖动时保留整组并限轴移动。
2. Ctrl/Command 点击或框选只减选；Shift+Ctrl/Command 重复点击已选点仍保留。Shift 框选追加，普通框选替换；框收缩后不保留已离开框的新增点。
3. 方向键微调 1 px，Shift+方向键移动 10 px；拖动中 X/Y 切轴不跳回开始位置，同键再次按下解除。Alt 暂停吸附。
4. 勾选软选择或在画布按 O。半径默认 25%，输入数值后确认，或按 [ / ] 调整；橙色邻点按距离跟随，白色未选点保持。所有顶点带深色描边，青色表示已选，悬停增加外圈。每个选点产生自己的影响范围。
5. 选两个及以上控制点，拖外框角点等比缩放，移到任一角点外侧、光标变为旋转样式后拖动旋转；旋转开始后按 Shift 吸附 15°。四个角都可旋转，顶部不显示独立旋转点，框内空白仍可框选；精灵位置、尺寸和对象旋转数值不变。
6. 拖动、缩放、旋转或方向键连按过程中按 Escape，恢复该次点位和选区；调整过的半径也恢复。无操作时 Escape 退出晶格编辑。

本轮不包含晶格贝塞尔手柄或曲面网格显示扩展。
